# Cleanup, 2026-11-25

After the site was rebuilt to the instrument design, Adam asked for "a cleanup pass on the repo to remove anything dead, redundant, no longer relevant, etc. from our design work and testing and so on".

Nothing in the repository was committed, so git could not bring a deleted file back. Everything removed is in one archive first:

```
data/archive/cleanup-2026-11-25.tar.zst        # 97 MB, 636 files, paths relative to the repository root
zstd -dc data/archive/cleanup-2026-11-25.tar.zst | tar -t            # list it
mkdir -p data/archive/restored && zstd -dc data/archive/cleanup-2026-11-25.tar.zst | tar -x -C data/archive/restored   # restore it
```

Nothing under `data/` other than the new archive was touched. `docs/research/`, `method/`, `registry/` and the pipeline's sources of truth were not changed.

## Code removed

Each was found unused with `grep -rw` over `longshot/`, `tests/` and `tools/`, and the full build, every test and both browser checks pass after it (below). No page, data file or record changed: the build's counts, field file and every hashed name but `app.js`'s are the same as before.

- `longshot/ladder.py`: `days_words` (no caller anywhere); `date_words` and its `MONTHS` table and `datetime` import (called only by one test assertion); `mass_words`, an alias of `missions.tonnes_words` kept only for that test, and the import it needed. The test now calls `missions.tonnes_words`.
- `longshot/priors.py`: `spin_category` (no caller) and `SLOW` (no reader).
- `longshot/site/static/app.js`, branches no page reaches, the generated front page and the synthetic one alike:
  - the control helper's case for buttons (both pages use radio groups) and the form's click handler for `view` and `m` buttons;
  - finding the zoom buttons by `data-zoom` or by their text (both pages name them `zoom-out`, `zoom-in`, `zoom-reset` in the form);
  - looking for the zoom output outside the form, and writing the count without its label (both pages have them).
  The `app.js` file is 868 bytes smaller (38,186 bytes).
- `tests/test_field_format.py`: the zoom button check no longer accepts `data-zoom`, which nothing writes.
- `tests/test_build.py`: the cache-header case used `/list/surface.html`, a page that no longer exists; it uses `/list/observe.html`.

The mockup's zoom URL hook (`?zoom=8&cx=…`) did not come across into the real site; nothing to remove.
